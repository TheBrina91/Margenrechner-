# Margen-Rechner für Marktplatz-Artikel

Kleine Web-App, die sofort zeigt, ob sich ein Artikel auf einem Marktplatz lohnt.

## Warum?

Marktplatz-Gebühren werden vom **Brutto**-Preis berechnet, Marge und Versandkosten aber **netto**.
Im Alltag führt das schnell zu Rechenfehlern und zu Artikeln, die am Ende Verlust machen.

## Was die App kann

- Verkaufspreis, Einkaufspreis, Versandkosten und Provision eingeben
- Umsatzsteuer (19 %) wird automatisch herausgerechnet
- Ergebnis: Netto-Gewinn bzw. Verlust und Marge pro Artikel
- Farbanzeige: grün = Gewinn, rot = Verlust
- Kosten werden als Balkendiagramm aufgeteilt
- Passt sich automatisch an Hell- und Dunkelmodus an

## Wie entstanden

- Rechenweg und Anforderungen: selbst entwickelt (Ausbildung Kauffrau im E-Commerce)
- Konzept und Rechenlogik mit **Gemini** vorbereitet
- Umsetzung als Web-App mit **Claude**
- Getestet und angepasst in Visual Studio Code

## Technik

HTML, CSS, JavaScript – läuft direkt im Browser, ohne Installation.
